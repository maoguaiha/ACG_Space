### 📦 一、 后端系统层 (核心服务)

**基础脚手架：** 基于 **RuoYi-Vue** 企业级敏捷开发框架 (改造适配 Spring Boot 3.x + Java 17)。

| **模块 / 领域**  | **核心依赖 (Maven/Gradle)**                     | **推荐版本** | **选型理由 / 架构师注**                                      |
| ---------------- | ----------------------------------------------- | ------------ | ------------------------------------------------------------ |
| **核心框架**     | `spring-boot-starter-web`                       | 3.2.x        | 底层 HTTP 与容器服务 (内嵌 Tomcat/Undertow)。                |
| **安全与权限**   | `spring-boot-starter-security` `jjwt`           | 3.2.x 0.12.x | 负责后台登录鉴权与前台 VIP 接口拦截，JWT 签发。              |
| **持久层与 ORM** | `mybatis-plus-boot-starter` `mysql-connector-j` | 3.5.x 8.3.x  | MyBatis-Plus 提供开箱即用的单表 CRUD，大幅减少 XML 编写。    |
| **缓存与序列化** | `spring-boot-starter-data-redis` `fastjson2`    | 3.2.x 2.0.x  | **重点：** 建议采用阿里 `fastjson2` 实现自定义的 `FastJson2JsonRedisSerializer`。在重写 `RedisTemplate` 时，请务必注意 Bean 的精细化管理与名称显式指定，以防止与 Spring Boot 默认注入的组件产生 `BeanDefinitionOverrideException` 冲突。 |
| **消息队列**     | `rocketmq-spring-boot-starter`                  | 2.2.x        | 支撑积分系统的异步削峰。建议在消费者侧配置幂等性校验。       |
| **云存储**       | `aliyun-sdk-oss`                                | 最新版       | 用于后台上传番剧海报、文章配图。                             |
| **工具与校验**   | `lombok` `spring-boot-starter-validation`       | -            | 减少样板代码，保障入参安全（防止恶意刷分、非法评论）。       |

### 🎨 二、 管理端前端 (运营后台)

**基础脚手架：** 基于 Vite + **Vue 3** (RuoYi-Vue 配套的前端工程)。

| **模块 / 领域**  | **核心依赖 (NPM/Yarn)**                     | **选型理由 / 架构师注**                               |
| ---------------- | ------------------------------------------- | ----------------------------------------------------- |
| **核心框架**     | `vue` (v3.4+) `vue-router` (v4)             | 采用 Composition API 构建，维护性极佳。               |
| **状态管理**     | `pinia`                                     | 取代 Vuex，提供更优的 TypeScript 支持和扁平化架构。   |
| **UI 组件库**    | `element-plus`                              | 支撑数据表格、字典配置表单、权限树等复杂后台交互。    |
| **网络请求**     | `axios`                                     | 封装请求拦截器，统一定制 Token 携带与全局异常提示。   |
| **富文本编辑器** | `@wangeditor/editor` 或 `vditor` (Markdown) | 强烈建议支持 Markdown 渲染，方便 PGC 内容的高效排版。 |

### 🚀 三、 用户端前端 (前台展示)

**基础脚手架：** 使用 `npx nuxi@latest init` 初始化的 **Nuxt 3** 工程。

| **模块 / 领域** | **核心依赖 (NPM/Yarn)**       | **选型理由 / 架构师注**                                      |
| --------------- | ----------------------------- | ------------------------------------------------------------ |
| **核心框架**    | `nuxt` (v3.x)                 | 原生支持 SSG 静态站点生成，极速的首屏加载与完美的搜索引擎爬虫 (SEO) 抓取体验。 |
| **状态管理**    | `@pinia/nuxt`                 | 管理用户侧的登录状态、积分头衔以及全局配置。                 |
| **CSS 引擎**    | `@nuxtjs/tailwindcss`         | 实用优先的原子类 CSS 框架。极其适合内容类社区，打包后 CSS 体积极小。 |
| **网络请求**    | `ofetch` (Nuxt 3 内置)        | 无需额外安装 Axios。原生支持服务端/客户端两端的同构请求拦截。 |
| **图标与样式**  | `iconify` / `lucide-vue-next` | 提供海量的 SVG 矢量图标（用于交互按钮、等级徽章），不依赖外部字体文件。 |
| **时间处理**    | `dayjs`                       | 轻量级时间格式化工具，用于展示“刚刚”、“2小时前”等友好的评论时间。 |

### 🛠️ 四、 基础设施与运行环境

- **Java 运行环境：** JDK 17 (或 JDK 21，若希望利用虚拟线程进一步提升并发性能)
- **Node.js 环境：** Node.js 18.x 或 20.x LTS (前端打包与 Nuxt 运行强依赖)
- **数据库引擎：** MySQL 8.0.x (默认开启 InnoDB 引擎)
- **缓存引擎：** Redis 6.2+
- **消息代理：** RocketMQ 5.x (建议初期单 Master 部署，后续视流量平滑扩容)
- **反向代理：** Nginx 1.24+ (用于托管打包后的 Nuxt 静态文件并反代后端的 API 接口)
