# ACG Space Agent 应用 — 部署与验证指南 V1.0

> 日期：2026-07-28  
> 适用版本：Phase 0~5 全部已落地

---

## 1. 前置条件

| 组件 | 要求 |
|------|------|
| JDK | 17+（推荐 Temurin 21） |
| Maven | 3.9+ |
| Node.js | 22（参见 `front-ui/.nvmrc`） |
| Python | 3.11+ |
| MySQL | 8.0 |
| Redis | 7+ |
| RocketMQ | 5.2.0（可选的，Agent 不直接依赖） |
| Docker | 24+（使用 `docker-compose.yml` 一键启动时） |

**API Key**：需申请
- **LongCat** chat key → 写入 `LLM_API_KEY_CHAT`（平台：`api.longcat.chat`，模型 `LongCat-2.0`）
- **通义** embedding key → 写入 `LLM_API_KEY_EMBED`（阿里云百炼 / DashScope，模型 `text-embedding-v3`）

## 3. Python Agent 部署

```bash
cd python-agent

# 3.1 创建虚拟环境并安装依赖
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3.2 配置密钥（务必不要提交到 Git）
cp .env.example .env
# 编辑 .env，填入：
#   LLM_API_KEY_CHAT=<你的 LongCat key>
#   LLM_API_KEY_EMBED=<你的通义 key>
#   LLM_CHAT_MODEL=LongCat-2.0
#   LLM_EMBED_MODEL=text-embedding-v3

# 3.3 启动（默认 8000 端口）
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**验证**：`curl http://localhost:8000/health` 返回 `{"status":"ok","chunks":19}`（19 段语料 = 规则 + FAQ）。

## 4. Java 门面部署

```bash
cd backend

# 4.1 确保 application-dev.yml 中 MySQL/Redis 连接正确
# 4.2 确保 application.yml 中 agent.api.base-url 指向 Python agent
#     （默认 http://localhost:8000，Docker 下自动覆盖为 http://python-agent:8000）

# 4.3 编译
mvn clean package -DskipTests

# 4.4 启动
mvn spring-boot:run
# 或
java -jar target/acg-space-backend-1.0.0-SNAPSHOT.jar
```

**验证**：`curl http://localhost:18083/api/agent/conversations -H "Authorization: Bearer <JWT>"` 返回 HTTP 200 空列表。

## 6. Docker Compose 一键启动

```bash
# 在仓库根目录执行
docker compose up -d
```

**服务清单**：

| 服务 | 端口 | 备注 |
|------|------|------|
| `mysql` | 13306 | MySQL 8.0 |
| `redis` | 6379 | Redis 7 |
| `rmqnamesrv` / `rmqbroker` | 9876 / 10909 | RocketMQ（Agent 不直接依赖） |
| `backend` | 18083 | Java 门面（含 AgentController） |
| `python-agent` | 8000 | AI 大脑（RAG + LLM + Bangumi） |

> Docker Compose 下前端需单独构建（`front-ui` 另有独立 `Dockerfile`）。

## 7. 端到端验证

### 7.1 Python ← 云端 LLM

```bash
cd python-agent
source venv/bin/activate
python scripts/selftest_live.py
```

**预期**：2 个用例 PASS（RAG 抽赏问答 + Bangumi 番剧推荐 function calling）。

### 7.2 Java ← Python SSE

```bash
# 需要先获取有效 JWT token（登录后端拿到的 token）
curl -N -X POST http://localhost:18083/api/agent/chat \
  -H "Authorization: Bearer <JWT>" \
  -H "Content-Type: application/json" \
  -d '{"message":"抽赏保底是什么？","conversationId":null}'
```

**预期**：SSE 逐 token 流式返回，结尾 `{"type":"done","content":""}`。

### 7.3 前端全链路

1. 启动 front-ui `npm run dev`
2. 浏览器 `http://localhost:3000` → 登录
3. 点击导航栏 **「AI 助手」**
4. 输入问题 → 发送 → 观察流式逐字输出
5. 点击「停止」→ 流中断
6. 左侧可新建/切换/删除会话

### 7.4 限流熔断验证

```bash
# 10 次/秒 以上触发 agentStream 限流 → 返回 429 错误帧
for i in $(seq 1 15); do
  curl -s -X POST http://localhost:18083/api/agent/chat \
    -H "Authorization: Bearer <JWT>" \
    -d '{"message":"hello"}' &
done
wait
```

**预期**：部分请求返回 `{"type":"error","content":"请求过于频繁，请稍后再试"}`。

## 8. 故障排查

| 现象 | 排查步骤 |
|------|----------|
| python-agent 启动失败 | 检查 `.env` 中 `LLM_API_KEY_CHAT` / `LLM_API_KEY_EMBED` 是否已填写 |
| `agent 上游流异常` | Java 日志查看 Python agent 是否可达（`curl python-agent:8000/health`） |
| Nuxt 返回 401 | 检查 `Authorization: Bearer <token>` 是否有效；Token 是否过期 |
| Nuxt 无流式输出 | 检查 `server/api/agent/chat.post.ts` 的 `text/event-stream` header |
| RAG 检索为空 | 检查 `corpus/` 目录文件存在 + 调 `POST /rebuild` 重建索引 |
| 模型返回错误 | LongCat：确认 `LLM_CHAT_MODEL=LongCat-2.0`；通义 embedding：`LLM_EMBED_MODEL=text-embedding-v3` |

## 10. 架构速览

```
浏览器 (Nuxt 3)
    │ POST /api/agent/chat
    ▼  (Authorization: Bearer <JWT>)
Nitro Server (server/api/agent/chat.post.ts)
    │ fetch + ReadableStream
    ▼
Java 门面 (AgentController / AgentServiceImpl)
    │ WebClient SSE
    ▼
Python Agent (FastAPI /chat)
    │ RAG 检索 (文本 → embedding → 余弦)
    │ + LLM(LongCat-2.0, stream=true, function calling)
    │ + 只读 Bangumi 工具 (search/detail/calendar)
    ▼
云端 (LongCat API / 通义 Embedding / Bangumi 镜像)
```
