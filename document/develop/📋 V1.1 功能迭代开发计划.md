| `/api/article/comment/{id}/reply` | POST | 文章评论回复 |

| `/api/article/comment/page` | GET | 原有分页 + 回复预览 |

### 回复逻辑

```
用户A: "这番真好看" (comment id=100)
  ├── 用户B回复用户A: "确实" → parentId=100, replyToUserId=A
  └── 用户C回复用户A: "我也觉得" → parentId=100, replyToUserId=A
      └── 用户A回复用户C: "感谢!" → parentId=100, replyToUserId=C
```

前端展示（B 站风格）:
```
[主评论] 用户A: 这番真好看       ← 点赞 | 回复
  ├─ 用户B → @用户A: 确实
  ├─ 用户C → @用户A: 我也觉得
  │ └─ 用户A → @用户C: 感谢!
  └─ [共 3 条回复 ▾]            ← 点击展开讨论详情
```

## 关键修复记录

### 点赞/点踩功能问题修复
1. **问题**: 重复点赞/点踩导致计数持续增加
   - **根因**: MyBatis-Plus `@TableLogic` 注解导致删除操作变为逻辑删除，查询时自动过滤已删除记录
   - **修复**: 使用 `baseMapper.delete()` 进行物理删除，绕过逻辑删除机制

2. **问题**: 评论点踩计数不更新
   - **根因**: `ArticleCommentVO` 缺少 `dislikes` 字段
   - **修复**: 在 VO 中添加字段并在 `toVO` 方法中设置值

3. **问题**: 点踩弹窗位置不居中
   - **根因**: 弹窗未挂载到 body，受父容器滚动影响
   - **修复**: 使用 Vue `Teleport` 组件将弹窗挂载到 body

## 开发注意事项

### 避免重复踩坑（参考 document/study/study.md）
1. **VO/DTO 字段同步**: 添加实体类字段后务必同步更新对应的 VO 类
2. **逻辑删除陷阱**: MyBatis-Plus 的 `@TableLogic` 会影响删除和查询操作
3. **变量定义完整性**: 复制代码时确保变量定义完整
4. **弹窗定位**: 使用 Teleport 确保弹窗始终在视口居中

## 代码约定

### 后端
- 响应格式统一使用 `Result<T>`
- 接口参数必须使用 `@Validated` 校验
- 使用 `SecurityUtils.getUserId()` 获取当前用户
- 数据库操作使用 MyBatis-Plus

### 前端
- TypeScript 禁止使用 `any` 类型
- 响应式变量使用 `ref()` 或 `reactive()` 定义
- API 调用统一在 `useApi.ts` 中封装
- 使用 Pinia 进行状态管理
