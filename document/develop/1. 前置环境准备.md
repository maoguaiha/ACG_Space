运行该项目需要按照以下步骤进行环境准备和启动。本项目包含**后端 (Spring Boot 3)**、**管理端 (Vue 3)**、**用户端 (Nuxt 3)** 以及 **基础设施 (Docker)**。

### 1. 前置环境准备

确保你的本地开发环境已安装以下工具：

- **JDK 17** (必须，Spring Boot 3 要求)
- **Node.js 18.x 或更高版本** (Nuxt 3 建议)
- **Docker & Docker Compose** (用于启动数据库和中间件)
- **Maven 3.8+** (用于构建后端)

------

### 2. 启动基础设施 (MySQL, Redis, RocketMQ)

项目根目录下提供了 `docker-compose.yml`，可以一键启动所有中间件。

```
powershell





# 在项目根目录执行

docker-compose up -d
```

- **MySQL**: 端口 `3306`，密码 `123456`。容器启动时会自动执行 `backend/sql/schema.sql` 完成数据库初始化。
- **Redis**: 端口 `6379`，无密码。
- **RocketMQ**: NameServer 端口 `9876`，Broker 端口 `10911`。

------

### 3. 启动后端服务 (Backend)

1. **进入目录**: `cd backend`

2. **配置文件**: 确认 `src/main/resources/application-dev.yml` 中的数据库和中间件地址是否正确（默认指向 `127.0.0.1`）。

3. 运行

   :

   - **IDE**: 运行 `com.ruoyi.project.ACGApplication` (或对应的启动类)。
   - **命令行**: `mvn spring-boot:run`

------

### 4. 启动管理端 (Admin UI)

管理端用于内容管理，基于 Vue 3 + Element Plus。

1. **进入目录**: `cd admin-ui`
2. **安装依赖**: `npm install`
3. **启动**: `npm run dev`
4. **访问**: 默认地址通常为 `http://localhost:5173`。

------

### 5. 启动用户端 (Front UI)

用户端是展示给最终用户的界面，基于 Nuxt 3 + Tailwind CSS。

1. **进入目录**: `cd front-ui`
2. **安装依赖**: `npm install`
3. **启动**: `npm run dev`
4. **访问**: 默认地址为 `http://localhost:3000`。

------

### 💡 运行贴士

- **首次运行**: 请务必先运行 `docker-compose`，因为后端启动时会检查 MySQL 和 Redis 连接。
- **端口占用**: 如果你的 `3306` 或 `6379` 端口已被本地服务占用，请先停止本地服务或修改 `docker-compose.yml` 中的端口映射。
- **接口地址**: 前端通过代理或配置连接到后端的 `8080` 端口，请确保后端服务正常运行。
