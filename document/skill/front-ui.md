此技能旨在指导创建专为二次元文化和数字资产交易社区量身定制的、独具特色的生产级前端界面。请实现真正可运行的 Vue 3 / Nuxt 3 代码，并对 ACG 美学细节、抽卡（Gacha）机制和创意选择给予极高的关注。

用户会提供前端需求：需要构建的组件、页面或应用模块。

## 设计思维 (Design Thinking)

在编码之前，请深入理解 ACG_Space 的业务背景，并确立一个**大胆且鲜明**的美学方向：
- **目标 (Purpose)**：这个界面解决了什么问题？是用于强 SEO 导向的内容（动漫百科/博客），还是高交互的 CSR 模块（抽卡、集市交易）？
- **基调 (Tone)**：选择一种鲜明的二次元风格：赛博朋克/机甲风（霓虹、暗色调、网格重度使用）、卡哇伊/马卡龙风（柔和、圆润、俏皮）、杂志/漫画风（黑白单色调辅以高对比度网点图案），或 抽卡手游高级感（毛玻璃效果，SSR稀有度标志性的耀眼金/紫光效）。以此为灵感，设计出忠于该方向的作品。
- **约束 (Constraints)**：Nuxt 3（需考虑 SSR/CSR 混合渲染）、Vue 3 组合式 API (Composition API)、使用 Tailwind CSS 进行样式设计。对于重动效的页面，性能至关重要。
- **差异化 (Differentiation)**：是什么让这个页面**令人过目不忘**？例如：令人惊叹的“十连抽”动画，或是极具爽感的拖拽式碎片合成交互。

**核心原则 (CRITICAL)**：选择一个清晰的概念方向并精准执行。无论是大胆的极繁主义（如《女神异闻录 5》UI）还是精致的极简主义（如《尼尔：机械纪元》UI）都可以——关键在于**设计的刻意感（intentionality）**，而非简单的元素堆砌（intensity）。

然后，实现满足以下条件的可运行代码：
- 生产级别，并在 Nuxt 3 环境中功能完备。
- 视觉冲击力强、令人难忘，且深谙御宅族/ACG 文化。
- 对每一个细节都进行了精心打磨。

## 前端美学指南 (Frontend Aesthetics Guidelines)

重点关注：
- **排版与字体 (Typography)**：选择契合 ACG 主题的字体。避免使用 Arial 和 Inter 这种毫无特色的字体。选择更具个性化的字体：使用日式黑体/明朝体来营造纯正的动漫感，使用像素/位图字体来营造复古游戏氛围，或使用锐利的几何展示字体来凸显科幻主题。
- **色彩与稀有度主题 (Color & Rarity Theming)**：保持美学风格的统一。使用 CSS 变量确保全局一致性。贯彻严格的“稀有度色彩系统”（例如：灰色代表 N，蓝色代表 R，紫色代表 SR，金色/棱镜幻彩色代表 SSR）。使用带有锐利、发光点缀的主色调，远胜于平庸、胆怯的调色板。
- **动效 (Motion - 对于 ACG 至关重要)**：利用动画实现视觉效果和微交互。使用 GSAP、@vueuse/motion 或高级的 Tailwind 动画类。将精力集中在最具冲击力的瞬间：抽卡揭晓时的闪光爆发、碎片合成时的悬浮粒子，以及跳蚤市场列表的交错加载动效。
- **空间构图 (Spatial Composition)**：打破常规的布局。不对称设计。对角线视觉流。破格元素（例如角色立绘突破容器边界溢出展示）。
- **背景与视觉细节 (Backgrounds & Visual Details)**：营造氛围与深度，而不是默认使用纯色背景。使用毛玻璃效果（backdrop-blur）将 UI 分层叠加在丰富的动漫插画之上。应用富有创意的形式，如：网格渐变、噪点纹理、漫画网点、发光边框、自定义光标（如魔法棒或十字准星），以及颗粒覆盖层。

**绝不要**使用那种千篇一律的 AI 塑料审美，例如：老掉牙的企业级 SaaS 调色板、可预测的后台面板模式，以及缺乏上下文业务特征的模板化设计。

发挥创造力去解读需求，做出令人意想不到的设计选择，让人感觉这确实是为现代动漫社区量身定制的。根据不同的业务模块在明/暗主题和不同美学之间进行切换（例如：阅读博客时使用宁静的浅色主题，但在抽赏和集市模块中使用暗黑、霓虹闪烁的主题）。

**重点注意 (IMPORTANT)**：代码实现复杂度必须与美学愿景相匹配。抽卡（Gacha）页面需要极其精细的代码，辅以大量的动画和特效。而阅读页面则需要克制、精准，并极其注重留白与排版。优雅源于对愿景的出色执行。

请记住：你正在构建一个动漫社区的视觉灵魂。打破思维定式，全心全意致力于打造独具特色的、以御宅族为核心的愿景，向世人展示真正的创造力。
