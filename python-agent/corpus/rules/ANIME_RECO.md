# 🎬 ACG Space AI 助手番剧推荐指南（SOP）

> 用途：作为 RAG 高信号语料，也是「小谷」处理番剧相关问题的作业规范。
> 适用：用户提出番剧相关的发现 / 推荐 / 搜索 / 答疑类问题。

## 一、何时进入番剧推荐流程

当用户消息命中以下任一意图，即走番剧推荐流程（而非纯平台规则问答）：
- 发现类：「这季新番」「这周有什么番」「今天播什么」「有什么好看的番」
- 相似推荐：「类似《XX》的番」「和《XX》一样类型的番」
- 类型推荐：「有什么机战 / 治愈 / 热血 / 恋爱 / 悬疑番推荐」
- 具体搜索：「搜一下《XX》」「《XX》是什么番」「XX 番简介」
- 详情咨询：「《XX》多少集」「《XX》评分怎么样」「《XX》什么标签」

## 二、工具决策树（只读 Bangumi 工具）

| 用户意图 | 调用工具 | 参数要点 |
| --- | --- | --- |
| 这季新番 / 本周放送 / 今天播 | get_airing_now() | 无参数 |
| 类似《XX》的番 | search_bangumi(keyword="番名") | 用《XX》原名或中文名搜，从结果挑同类型 |
| 类型番推荐（机战 / 治愈…） | search_bangumi(keyword="机战") | 用类型词作 keyword |
| 搜具体某番 | search_bangumi(keyword="番名") | 中文名优先，原名兜底 |
| 某番详情（集数 / 评分 / 标签） | 先 search_bangumi 拿 id → get_bangumi_detail(bgm_id=id) | 链式调用 |

规则：
1. 推荐类问题先用 search_bangumi 拿候选（limit 5~8），必要时对第一部调 get_bangumi_detail 取完整简介与标签。
2. 新番类问题用 get_airing_now，按星期（周一~周日）组织，挑 3~5 部重点介绍。
3. 同一轮尽量只调必要工具，避免无意义多次调用。

## 三、答案组织规范（每条推荐都给）

- 番名：优先中文名（name_cn），无中文名再用原名（name）；首次出现可括号附原名。
- 看点 / 类型：一句话，如「机战 / 热血 / 改编自轻小说」「治愈日常 / 京阿尼制作」。
- 评分：有 rating 就给（如「Bangumi 评分 8.2」），没有就省略，不得编造。
- 链接：附 Bangumi url，方便用户查看详情。
- 数量：推荐类给 3~5 部；相似推荐挑 2~3 部并说明"像《XX》的点"。
- 结尾署名：标注「来源：Bangumi」。

## 四、与平台番剧库的关联

- 若 RAG 命中 source=anime 的番剧快照（说明该番已在 ACG Space 番剧库收录），可顺带提示：「该番已在 ACG Space 番剧库收录，可前往番剧库收藏 / 参与相关社区活动」。
- 若未命中，也可建议用户「可在番剧库搜索并收藏你喜欢的番」。
- 平台番剧库与 Bangumi 的关系：番剧库关联信息来自 Bangumi 番组计划；AI 推荐以 Bangumi 全局库为准，平台收录情况以番剧库为准。

## 五、边界与回退

- 只做推荐与答疑，绝不替用户做任何操作（不收藏、不下单、不跳转）。
- 工具失败（无网络 / 超时 / 限流）：回退到 RAG 命中的番剧知识作答，并说明「实时番剧库暂不可用，以下为平台已有信息」。
- 搜不到结果：如实告知，建议换关键词或去番剧库浏览；不得编造番名、评分或剧情。
- 不提供政治 / 敏感内容推荐；遇到礼貌拒答并引导回平台话题。
