# ACG Space 高频问答（FAQ）

> 用途：作为 RAG 高信号语料，回答用户最高频的玩法 / 操作类问题。
> 原则：不臆造具体数值；涉及概率 / 库存等变动项，引导用户以「当期奖池公示 / 站内信通知」为准。

## 抽赏相关

**Q：怎么进行抽赏（抽谷子）？**
A：进入「抽赏中心」选择当期奖池，点击单抽或十连即可抽取数字谷子（角色卡片）。每次抽取结果实时展示，抽到的 N / SR / UR 卡片进入你的「背包」。

**Q：抽赏有保底吗？**
A：平台设有保底机制，具体保底次数与当期奖池的概率分布以「抽赏中心 - 当期奖池公示」为准。建议抽前先查看该奖池的说明，了解各稀有度（N / SR / UR）的抽取概率与保底规则。

**Q：抽到的卡片有什么用？**
A：卡片存放在「背包」中。低稀有度（N）卡片可作为合成材料；高稀有度（SR / UR）可收藏，UR 碎片还能在「兑换中心」兑换实物周边。

## 合成相关

**Q：碎片怎么合成？**
A：在「合成工坊」中，可将多个低稀有度碎片合成为更高稀有度。常见规则为「10 个 N 碎片合成 1 个 SR 碎片」（具体配方以合成工坊当前展示为准）。合成可能消耗积分，且不同配方有不同的成功率。

**Q：合成失败会怎样？**
A：合成存在成功率，失败通常按配方规则返还部分材料或消耗积分，具体以当期合成配方说明为准。建议合成前确认配方与消耗。

## 兑换相关

**Q：怎么用 UR 碎片兑换实物？**
A：进入「兑换中心」，选择心仪的实物周边，使用 UR 碎片（及/或积分）兑换。兑换成功后会生成订单，进入「我的订单」查看与跟踪。

**Q：兑换的实物多久发货？**
A：订单创建后由运营在后台处理发货。具体发货时效以兑换商品页说明与站内信通知为准；可在「我的订单」中查看物流状态。

## 积分相关

**Q：积分怎么获得？**
A：积分可通过每日签到、社区互动（发帖 / 评论 / 点赞）、活动任务等方式获得，具体以「任务中心 / 活动页」当期规则为准。

**Q：积分有什么用？**
A：积分可用于合成工坊的配方消耗、部分兑换商品的抵扣等。积分不可提现，仅限平台内消费。

## 订单与物流

**Q：在哪里看我的订单和物流？**
A：进入「我的订单」，可查看所有兑换 / 购买订单及其状态（待发货 / 已发货 / 已完成）。已发货订单会展示物流信息，可点击查看物流轨迹。

**Q：客服入口在哪里？**
A：可在「我的 - 帮助与客服」中找到客服入口与常见问题。如遇订单、物流、账号等问题，建议先查看站内信与 FAQ，仍未解决再联系客服。

## 番剧库与番剧推荐

**Q：怎么让 AI 帮我推荐番剧？**
A：直接说需求就行，比如「有什么机战番推荐」「类似《CLANNAD》的番」「这季有什么新番」。小谷会调用 Bangumi 番剧库为你检索，并组织成带类型 / 评分 / 链接的清单（来源：Bangumi）。

**Q：这季有什么新番 / 这周有什么番在播？**
A：问「这季新番」或「这周有什么番」，小谷会调用 get_airing_now 拉取本周放送列表，按星期（周一~周日）给你整理几部重点番剧，并附 Bangumi 链接。

**Q：有什么类似《XX》的番推荐？**
A：告诉我你想找「类似《XX》」的番，小谷会先用《XX》的番名在 Bangumi 检索，再挑同类型 / 同风格的 2~3 部，并说明"像的点"（如同样治愈、同样机战）。

**Q：有什么机战 / 治愈 / 热血 / 恋爱番推荐？**
A：直接说类型词即可，如「机战番推荐」「治愈番推荐」。小谷会用类型词在 Bangumi 检索，给出 3~5 部带类型与评分的番剧清单。

**Q：推荐结果里的链接是什么？**
A：链接指向 Bangumi（番组计划）的番剧详情页，可在那里看完整简介、评分、标签与分集信息。

**Q：平台番剧库和 Bangumi 是什么关系？**
A：平台番剧库关联的番剧信息来自 Bangumi 番组计划。AI 推荐以 Bangumi 全局库为准；若该番已在 ACG Space 番剧库收录，可前往番剧库收藏并参与相关社区活动。

**Q：搜不到某番 / AI 说番剧库不可用怎么办？**
A：可换关键词（中文名 / 原名）再试，或到番剧库浏览收藏。若实时番剧库暂不可用，小谷会回退到平台已有番剧信息作答，并说明来源受限。
